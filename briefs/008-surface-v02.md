2. **The text (V2.11).** A pack is UTF-8, read as bytes are written — open it with no newline translation, or a CR LF inside a name is lost before you can refuse it. No CR byte, no surrogate code point, no coding declaration but UTF-8, and every identifier ASCII: Python folds identifiers to NFKC, so `ſcore` would otherwise be `score`.
3. **Records (V2.6, V2.7).** A multiplicity is decimal digits as written — check the source text, since `True`, `0x1` and `1_0` are all Python ints. No terminal's name begins `end:`. A falsifying record is a prefix `[draws, None, None]` or a full record with an after-report; a full record with none is refused PLATE.
4. **The digest (V2.13).** SHA-256 of `[counts, falsifiers]` as compact JSON, each string escaped **by the page's escape table**, first matching row deciding. Kit v0.11's digest — the Counts alone, Python's default `json.dumps` — is withdrawn; PLATE now checks the new one. The adapter gains `digest(counts, falsifiers)`; K7 checks it on the page's five vectors and on 200 fuzzed names holding quotes, backslashes, DEL, control, non-ASCII and astral characters. The one trap: DEL (U+007F) is escaped, `/` is not.
5. **The Score (V2.8).** A term for every copy of every record **and every falsifying record**, each under the prior conditioned on all the others. `score(world, counts, falsifiers=())` on the adapter; K7 checks attack session 5's refit at 363/10000, and that both of signed S14's readings are refused UNSCORED — SURFACE v0.2 decides over C2.S14 here, as the later page.
